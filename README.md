# Cybersecurity Portfolio

Welcome to my cybersecurity portfolio.

I created this repository to document some of the hands-on cybersecurity projects I have worked on and the skills I am building along the way. My work spans areas such as network security, incident investigation, cloud security, SOC operations, and other security-focused projects.

## Projects

### 1. [Network Forensics Investigation](01-network-forensics-investigation)

Used Wireshark, DHCP logs, and security logs to investigate suspicious activity and trace it from a source IP address to a host device and user account.

**Skills:** Wireshark, SMTP analysis, packet analysis, DHCP log analysis, security log analysis, network forensics, incident investigation.

### 2. [Phishing Email Investigation](02-phishing-email-investigation)

Analyzed PCAP files in Wireshark to identify phishing emails, review suspicious email content, and trace the activity back to its source using SMTP and network information.

**Skills:** Wireshark, PCAP analysis, SMTP filtering, phishing detection, email analysis, source IP identification, network forensics.

### 3. [Linux File Monitoring with Auditd](03-linux-auditd-file-monitoring)

Used Linux `auditd` to monitor file changes, create audit rules, and review audit logs to identify activity on a monitored file.

**Skills:** Linux, auditd, auditctl, ausearch, file integrity monitoring, log analysis, host-based intrusion detection, incident investigation.

### 4. .[Linux Auditd Attack Investigation](04-linux-auditd-attack-investigation).

Used Linux Audit (auditd) to monitor protected files, analyze audit logs, and identify which simulated attack scripts modified specific files on the system.

Skills: Linux, auditd, auditctl, ausearch, file integrity monitoring, log analysis, incident investigation, host-based intrusion detection, attack attribution.

### 5. [Snort Network Intrusion Detection](05-snort-network-intrusion-detection)

Used Snort 3 to analyze PCAP traffic, create custom intrusion-detection rules, and identify credential file access and directory traversal activity while improving rule specificity to reduce unnecessary alerts.

**Skills:** Snort, NIDS, PCAP analysis, tcpdump, network traffic analysis, signature-based detection, rule tuning, incident investigation.

### 6. [Snort Directory Traversal Investigation](06-snort-directory-traversal-investigation)

Exploited a directory-traversal vulnerability in a controlled lab, created Snort rules to detect the attack, and analyzed packet captures to determine which files the attacker successfully accessed.

**Skills:** Snort, IDS rule creation, tcpdump, PCAP analysis, directory traversal, network intrusion detection, breach scoping, Linux permissions, incident investigation, security remediation.
